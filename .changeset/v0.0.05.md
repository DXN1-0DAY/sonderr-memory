# TUI-heavy context engine for AI coding agents.

## v0.0.05

- Split TUI into modular panels: sidebar, editor, metadata, timeline
- Add global error handling with TUIError class
- Add CLI layer with subcommands: tui, remember, search, list, timeline, stats, context, export
- Add config system with theme support
- Add utility modules: array helpers, format helpers, store helpers
- Expand memory system with meta, timeline, related entries, context export

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/DXN1-termux/sonderr-memory/main/install.sh | bash
```

## Usage

```bash
sonderr-memory            # launch TUI
sonderr-memory remember "idea text"
sonderr-memory search "query"
sonderr-memory list
sonderr-memory stats
```
